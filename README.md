# ECOVIX — Acervo de projetos

Aplicativo instalável para consulta de desenhos PDF e modelos 3D, com favoritos locais e download dos projetos escolhidos para uso offline.

Abra o link completo recebido do responsável. A chave está no fragmento do endereço e não faz parte deste repositório. Catálogo, miniaturas, documentos e modelos são publicados criptografados. O logo e o programa são públicos.

Não há cadastro online nem senha. O perfil e os favoritos pertencem ao aparelho. Quem receber o link completo pode encaminhá-lo.

No Android, use a opção de instalar do Chrome. No iPhone, use Safari → Compartilhar → Adicionar à Tela de Início. Após instalar, baixe os projetos desejados dentro do aplicativo. Se o aplicativo pedir liberação, cole o link completo recebido.

O primeiro acesso e os downloads precisam de conexão. O navegador pode remover o armazenamento se houver falta de espaço. Confira o filtro “No aparelho” antes de consultar sem internet.

Nunca publique chaves, links completos, fontes CAD ou arquivos de projeto sem criptografia.
